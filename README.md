# 📰 News-App

A dynamic news application built using HTML, CSS, and Vanilla JavaScript to explore news articles.

## ✨ Features

* 🔗 NewsAPI integration to fetch news articles dynamically.
* 🔍 Search functionality to find news by keywords.
* 🏏 Category-based filtering for IPL, Finance, and Politics.
* ⚡ Asynchronous API requests using Fetch API and Promises.
* 🔄 Dynamic DOM manipulation to display news results.
* 📱 Responsive and user-friendly UI.

## 🛠️ Technologies Used

HTML5 • CSS3 • JavaScript (ES6+) • REST API • Fetch API • JSON
